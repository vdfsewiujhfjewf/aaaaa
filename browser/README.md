# Mini Web Browser

シンプルな HTML/CSS/JavaScript だけで動作するミニ Web ブラウザです。URL を入力すると、ページが iframe 内に表示されます。戻る・進む・再読み込みの基本操作も備えています。

## 使い方

1. 任意の HTTP サーバで `index.html` を公開します。ローカルで試す場合は、プロジェクトルート（この README と同じ階層）で次のコマンドを実行してください。
   ```bash
   # Python 3 が入っている場合
   python -m http.server 8000

   # もしくは Node.js がある場合
   npx serve . -l 8000
   ```
2. ブラウザで <http://localhost:8000/browser/index.html> を開きます。VS Code の Live Server 機能など、ほかの静的サーバでも構いません。
3. 上部のアドレスバーに URL を入力し、Enter キーまたは「移動」ボタンを押すとページが読み込まれます。
4. アドレスバーの下にある検索欄にキーワードを入れて「検索」を押すと、DuckDuckGo の検索結果が表示されます。
5. 表示が更新されない場合は、読み込み状況がステータスバーに表示されているか、エラー画面が出ていないか確認してください。

## 機能

- 入力欄にスキーム（`https://` など）がなくても自動補完します。
- 履歴を保持しており、「戻る」「進む」ボタンで移動できます。
- 読み込み状況をステータスバーに表示します。
- 誤った URL を入力した場合はアプリ内エラー画面を表示します。
- DuckDuckGo を使ったキーワード検索が可能です。

> **注意:** 多くのサイトはセキュリティ上の理由から iframe での表示を禁止しています。その場合はページが表示できないことがあります。
