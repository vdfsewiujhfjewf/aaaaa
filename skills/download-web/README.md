# Skills Download Web

別アプリで開くために、skills を ZIP でダウンロードするための簡易Webアプリです。

## 起動

```bash
python3 skills/download-web/app.py
```

起動後に以下を開いてください。

- <http://127.0.0.1:8787>

## ダウンロードできる内容

- `all.zip`（3スキル + `START_HERE.md`）
- `skript-code-specialist.zip`
- `javascript-code-specialist.zip`
- `code-repair-specialist.zip`
